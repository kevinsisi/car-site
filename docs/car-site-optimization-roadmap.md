## 1. 現況:car-site vs HANK豪車館 正面對決

| 維度 | car-site | HANK豪車館 | 結果 |
|---|---|---|---|
| 比較功能 | URL 可分享 `?ids=`、localStorage 跨頁保留、CompareBar 全站常駐 | 跨頁清單遺失 bug、不可分享、`/compare/`+`/compare-list/` 重複頁 | ✅ 本站大勝 |
| SEO 結構化 | Vehicle JSON-LD + BreadcrumbList + OG + sitemap + robots | OG 0 個、JSON-LD 0 個、無 sitemap | ✅ 本站大勝 |
| 售出車呈現 | 「已售出」標章 + 成交實錄 tab + 首頁成交案例區 | 155 台售出但完全無標示 | ✅ 本站勝 |
| 線上留客 | 賣車表單(10 張照片上傳)+ SMTP 通知 + 後台線索管理 | 無任何表單 | ✅ 本站勝 |
| 相簿 | lightbox(雙指縮放/鍵盤)+ 4 種模式可切 | Swiper 輪播,無 lightbox | ✅ 本站勝 |
| 社群信任資產 | 無數據牆 | 1M YT 訂閱/104M 觀看數據牆、IG/TikTok 矩陣 | ❌ 對手勝(內容營運) |
| 視覺一致性 | 依上傳照片而定 | 全車統一棚拍場景 | ❌ 對手勝(攝影流程) |
| 單車影片 | 無(影片僅站級) | 無 | ➖ 共同缺口 |
| 篩選維度 | 品牌 + tab + 全文搜尋 + 排序 | 在庫/品牌/車型三維 + 計數聯動 | ⚠️ 互有勝負 |
| 大量庫存擴展 | 無分頁(全部一次渲染) | 29 頁分頁 | ⚠️ 對手較可擴展 |

**結論:技術面本站已領先;對手的優勢全部在「內容與信任營運」(社群數據、棚拍一致性、155 台成交量體)。**

## 2. P0 — 立即做(實證高信度 + 低工程量)

### 2.1 比較表體驗升級 ✅(Baymard/NN.g 3-0 一致,67% 使用者會用比較功能)
本站比較架構已勝對手,照實證 UX 再補四件事:
1. **「只顯示差異」開關**:隱藏所有車輛數值相同的列(Baymard:更快解析差異、降低認知負荷;優於僅高亮)
2. **屬性分組小標**:規格列依「外觀 / 動力 / 車況」分組(優於平鋪清單)
3. **sticky 欄頭**:捲動時車名+縮圖(+價格)固定在頂部
4. **上限 3~5 台**;手機維持橫向捲動但加捲動提示,或收成 tabs/分段清單(NN/g 2-1)
> 同時注意:比較表**最大失敗因素是內容不全**(3-0)——後台應要求每台車規格欄位完整一致,缺欄位的車在比較表顯示「—」而非空白。

### 2.2 信任訊號:評價/見證系統 ✅(BrightLocal n=1,002:97% 看評論、<20 則 47% 拒絕、回覆全部評論 +80% 考慮度)
1. 詳情頁/首頁加入**客戶見證區塊**(成交照 + 一句話 + 星等),後台可管理
2. **集中衝 Google Business Profile 評論到 20 則以上**,並回覆每一則 🟡(2-1;Google 占全網評論 ~71-73%)
3. 首頁成交案例區(已有)加上**累計成交數字計數器**——對手用「299 輛過戶/98% 滿意度」數據牆,本站有真實資料庫,可自動統計真數字(`status=sold` count),比對手手填更可信

### 2.3 結構化資料:維持但不要加碼 ✅(Google 官方 3-0)
- **Google 已於 2025-06-12 棄用 Vehicle Listing 富結果**(2025-07-31 生效)→ 不要投資車輛富搜尋顯示
- 現有 Vehicle JSON-LD + OG 保留(一般索引與社群預覽仍有效),**不需再擴充**
- OG 預覽卡在「價格電洽」情境的最佳化無實證(開放問題)→ 維持現狀即可

## 3. P1 — 差異化機會(中信度/競對缺口)

### 3.1 單車環景介紹影片 🟡(2-1:~90% 消費者想要 vs 僅 ~15% 車商提供;2023 廠商調查,注意偏差)
- 本站與對手都沒有「每台車的影片」——先做就是市場缺口
- 工程:`vehicles` 加 `videoUrl` 欄位(YouTube/MP4),詳情頁相簿首格或規格表下嵌入;admin 表單加欄位
- ⚠️ 不要引用「影片提升 90% 互動」「影片優於照片」等說法——**全部被否決(0-3)**;唯一站得住的是「想要 vs 供給」缺口
- 配套:老闆已有影音內容的話,把 YT 影片對應到車(對手的 YT 1M 訂閱是其最大資產,但影片從不進詳情頁)

### 3.2 篩選維度補齊 ⚪(競對觀察)
- 加「車型」(SUV/轎車/雙門跑車…)與「在庫/已售」checkbox 篩選 + **各選項即時計數**(對手 Filter Everything 的計數聯動是其列表頁最強體驗)
- 本站已是 SSR+client 過濾,實作成本低;同時補 URL 參數化(篩選狀態可分享——對手做不到)

### 3.3 庫存規模化準備 ⚪
- 加分頁或無限捲動(目前全量渲染,30+ 台後首屏會變重)

### 3.4 統一視覺(非工程,營運建議)⚪
- 對手最強的視覺資產是「全車同一棚拍場景」;建議制定拍攝規範(同角度序列、同背景),上傳時依規範排序——CMS 可加「封面 45 度角」提示文案

## 4. 不要做 / 不要信 ❌(對抗驗證否決,0-3 或 1-2)

| 流傳說法 | 判定 |
|---|---|
| 「線上即時聊天轉換率比表單高 3-5 倍 / 主動聊天 +40%」 | ❌ 0-3 → 不必為此上 chat widget |
| 「60-90 秒內回覆線索,轉換率三倍」 | ❌ 0-3 → 快回覆是好習慣,但別當 KPI 依據 |
| 「VDP 影片讓互動率從 20-30% 升到 90%」 | ❌ 0-3 |
| 「95% 買家說影片影響購買決策」 | ❌ 0-3 |
| 「影片展示效果必然優於照片」 | ❌ 0-3 |
| 「『電洽』是經過驗證的留客心理鉤子」 | ❌ 0-3 → 隱藏價格對 NT$5M-30M 客群的利弊**無實證**,雙向都沒證據;維持市場慣例即可,有量之後可 A/B |
| 「照片透明度 +30/40% 線索」 | ❌ 1-2(Dealer.com 白皮書無法溯源) |

## 5. 開放問題(研究無法回答,需自行實驗)

1. **台灣在地漏斗零實證**:LINE OA 圖文選單/自動回覆/VOOM 對車商的轉換數據、8891/好車網生態整合 ROI、TikTok/Reels 短影音成效——deep-research 沒有任何主張存活。→ 對手的 LINE OA 配置(預約賞車/出售愛車/導回官網)可當作市場慣例參考,效果自行量測。
2. **表單 vs LINE 誰轉換好**:chat 相關主張全滅後,此問題真空。本站兩者都有,建議在 admin 加「線索來源」統計欄位自行累積數據。
3. **隱藏價格利弊**:無證據。本站 schema 已有 price 欄位,可對部分車款試開價格做對照。

## 7. 2026-06-05 全站 UI/UX 自我稽核結果(vs 對手)

Playwright 全頁掃描(9 頁 × 桌面/手機、橫向溢出偵測、觸控目標、console error、fixed 元素行為):

**當日已修**
- CompareBar:三台車時桌面 152px→56px、手機 410px→49px(單列橫捲);根因是 runtime 注入節點不吃 Astro scoped styles(改 `is:global`)+ 壞縮圖 alt 文字撐高(`onerror` 自移除)
- 比較頁移除浮動 CompareBar(與頁面內容重複互蓋)
- 比較頁「加入車輛」改打字才出現(預設提示文字,zero-match 顯示找不到)
- 手機 header nav 與 footer 快捷連結觸控目標 <32px → 加大到 ~44px
- IG 輪播:點擊暫停/再滑恢復;卡片只露影片(裁掉 IG header 與按讚列)、禁內部捲動;標題留白 fallback「精選好車」
- Banner:開場零播放器元件(poster 蓋到 chrome 退場)、多影片循序播放、單影片自循環
- 全站無橫向溢出(桌面+手機 9 頁全過)

**對手仍領先(內容/營運面,非程式)**
- 全車統一棚拍場景的視覺一致性;1M YouTube 社群證明數據牆
- 深色奢華視覺(本站現用 carsmeet-blue 淺色;admin 有 champagne-black 可切換,屬營運選擇)

**結論:程式排版與互動層面已無輸給對手之處;剩餘差距集中在攝影規範與社群內容資產。**
